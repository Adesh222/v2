## How to run locally (Docker)
1. **Install Docker** (Desktop or Engine).
2. Open a terminal in the project root:
   ```bash
   cd "C:/Users/AIML-14/Downloads/goodwill meadiqueue"
   docker compose -f docker-compose.yml up --build
   ```
3. The backend will be available at `http://localhost:8000` and the UI at `http://localhost`.
4. Use the demo credentials (or the ones you created) to log in.

## Deploying to a cloud platform that supports Docker
- **Render / Railway / Fly.io** – simply connect your repository, enable Docker‑Compose, and the platform will build and run the three services.
- **Vercel** does **not** run full `docker‑compose` stacks. It can host the **frontend** as a static site, but the FastAPI backend would need to be deployed separately (e.g., as a Vercel Serverless Python function or on another provider). If you still want to use Vercel:
  1. Deploy the `frontend` folder as a Vercel project (it will use the `Dockerfile` under `frontend`).
  2. Deploy the `backend` as a separate Vercel Serverless Python function (create an `api/` folder with an `index.py` that imports your FastAPI app).  
  3. Update the frontend’s `VITE_API_URL` environment variable to point to the URL of the deployed backend.
